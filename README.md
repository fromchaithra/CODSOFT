# CODSOFT
# 🚀 CodSoft Java Development Internship Projects

This repository contains all the tasks I completed during my **Java Development Internship** at [CodSoft](https://www.linkedin.com/company/codsoft/).  
Each project is developed using **Java Swing (GUI)** and follows **object-oriented programming principles**.

---

## 📚 **Projects Included**

### 1️⃣ Number Game  
🎮 A fun guessing game where users try to guess a random number within limited attempts.  
**Concepts Used:** Random numbers, loops, conditionals, GUI event handling.

### 2️⃣ Student Grade Calculator  
🧮 A simple application that calculates total marks, average, and grade for given subjects.  
**Concepts Used:** Arrays, conditional logic, input validation, GUI components.

### 3️⃣ ATM Interface  
💳 A virtual ATM system allowing deposit, withdrawal, and balance inquiry with PIN authentication.  
**Concepts Used:** Encapsulation, class-based design, validation, event-driven UI.

### 4️⃣ Currency Converter  
💱 A user-friendly GUI-based currency converter supporting both **offline** and **live API** modes.  
**Concepts Used:** API handling (HTTP), parsing, mathematical operations, UI design.

### 5️⃣ Student Management System  
📚 A complete CRUD-based student management app with file storage and data persistence.  
**Concepts Used:** File handling, serialization, collections, OOPs, Swing components.
